# RoomForge – AI-Powered 3D Interior Design Assistant

## Project Overview

RoomForge is an interactive 3D interior design application that allows users to furnish and customize rooms or entire apartments. The application combines traditional 3D room planning with an AI-powered multi-agent system that can independently research furniture, design room layouts, and suggest improvements.

The goal is to create an application where users can design their living spaces manually while also collaborating with AI agents that can actively modify the 3D environment.

## 1. Interactive 3D Interior Design

The frontend is built using **React and React Three Fiber**, providing an interactive 3D environment.

Users can:

- Create and customize rooms or apartments with different dimensions.
- Browse furniture from a product catalog.
- Select, place, move, rotate, and remove furniture directly in the 3D environment.
- Manage an inventory of furniture they already own.
- View furniture properties such as dimensions, price, color, category, and style.
- Set a budget for additional furniture purchases.
- Save and load different room layouts.
- Compare different interior design variations.

Each furniture item has structured properties that both the user and AI agents can access and modify.

## 2. AI-Powered Interior Design

An integrated AI chat interface allows users to interact with their rooms using natural language.

For example:

- "Design a modern living room with a maximum budget of €1,500."
- "Move the desk closer to the window."
- "Find a cheaper alternative to this sofa."
- "Can you improve my current room layout?"
- "Use my existing furniture and create a more spacious arrangement."

Instead of only providing textual suggestions, the AI can directly modify the room by adding, removing, or repositioning furniture.

These modifications are reflected in the 3D environment, allowing users to inspect and adjust the proposed changes.

## 3. Multi-Agent Architecture

The backend uses **Python, FastAPI, and LangGraph** to orchestrate four specialized AI agents.

### Agent 1: Conversation & Preferences Agent

Acts as the main interface between the user and the AI system.

Responsibilities:
- Understand user requests and intentions.
- Store and retrieve user preferences, such as preferred styles, colors, and budgets.
- Access the current room state and previous interactions.
- Decide which specialized agent should handle a particular request.
- Respond to general questions about the room and its furniture.
- Coordinate multi-step requests involving multiple agents.

This agent acts as the main coordinator but does not necessarily execute every request itself.

### Agent 2: Furniture Research Agent

Responsible for finding suitable furniture based on the user's requirements.

Responsibilities:
- Search an internal furniture catalog.
- Filter furniture by price, dimensions, colors, materials, and style.
- Check whether suitable items already exist in the user's inventory.
- Compare different furniture options.
- Recommend alternatives when products do not meet the requirements.
- Potentially integrate external furniture providers or APIs in the future.

An optional future extension could allow the agent to generate or customize furniture models.

### Agent 3: Interior Designer Agent

Responsible for creating and modifying room layouts.

Responsibilities:
- Interpret the user's design requirements.
- Analyze room dimensions, doors, windows, and existing furniture.
- Select suitable furniture in cooperation with the Research Agent.
- Determine furniture positions and rotations.
- Create complete room layouts or modify individual parts of an existing layout.
- Consider practical requirements such as accessibility, available space, and furniture placement.
- Generate multiple design variations.

The agent produces structured room modifications that can be applied to the 3D scene.

### Agent 4: Design Critic Agent

Acts as an independent evaluator of existing or proposed room designs.

Responsibilities:
- Analyze the current room layout.
- Identify potential problems with furniture placement.
- Evaluate whether the layout satisfies user preferences.
- Suggest improvements related to space utilization, functionality, aesthetics, and budget.
- Review designs generated by the Interior Designer Agent.
- Provide feedback directly to the user without requiring another agent to initiate the analysis.

For example, the user can simply ask:

"What's wrong with my current room design?"

The Critic Agent can inspect the room independently and suggest improvements.

## 4. Dynamic Agent Orchestration

LangGraph provides a flexible multi-agent architecture in which agents dynamically delegate tasks, invoke tools, and collaborate based on the user's request and intermediate results. The system does not follow predefined execution sequences. Instead, agents independently determine when specialized assistance is required, while deterministic validation and execution limits ensure reliable modifications to the 3D environment.

## 5. Tools and Room State Management

Agents interact with the application through specialized tools rather than directly modifying frontend components.

Potential tools include:

- `get_room_state()` – Retrieve the current room and furniture configuration.
- `get_user_preferences()` – Retrieve stored user preferences.
- `search_furniture()` – Search available furniture.
- `get_inventory()` – Retrieve already owned furniture.
- `place_furniture()` – Add furniture to a layout.
- `move_furniture()` – Change furniture positions and rotations.
- `remove_furniture()` – Remove furniture from a layout.
- `check_collisions()` – Detect overlapping furniture.
- `validate_layout()` – Validate dimensions, room boundaries, and accessibility constraints.
- `calculate_total_cost()` – Calculate the cost of a design.
- `save_layout()` – Save a proposed layout.

The application maintains a structured room state containing room dimensions, furniture objects, positions, rotations, inventory, and budget information.

Geometry validation and collision detection are handled through deterministic algorithms rather than relying entirely on LLM reasoning.

AI-generated changes can first be applied to a temporary layout and presented to the user before being committed to the actual room state.

## 6. Long-Term Memory and Personalization

The application stores relevant user preferences across sessions.

Examples include:

- Preferred interior design styles.
- Favorite colors and materials.
- Budget preferences.
- Previously rejected furniture or designs.
- Existing furniture inventory.
- Saved room layouts.

This allows agents to provide more personalized recommendations over time without requiring users to repeat their preferences.

## 7. Technical Architecture

**Frontend**
- React
- React Three Fiber / Three.js
- Interactive 3D room editor
- Furniture catalog and inventory management
- AI chat interface
- Room layout comparison and preview

**Backend**
- Python with FastAPI
- LangGraph for agent orchestration
- LangChain for LLM and tool integration
- Structured tool calling
- Room state management and geometric validation
- Database for furniture, layouts, and user preferences
- Optional vector database for semantic furniture search and long-term memory

## 8. Project Goal and MVP

The initial version focuses on creating a working end-to-end application rather than a fully featured interior design platform.

The MVP should support:

- One configurable room with doors and windows.
- A small furniture catalog with predefined 3D models.
- Manual furniture placement and manipulation.
- A personal furniture inventory.
- Natural-language interaction with the AI.
- Four specialized agents with dynamic routing.
- AI-generated room layouts and furniture recommendations.
- Automatic collision and boundary validation.
- Independent design feedback.
- Saving and loading room layouts.

Advanced features such as complete apartment planning, external furniture marketplaces, realistic lighting analysis, and AI-generated 3D furniture models can be added later.

## 9. Expected Outcome

The final product demonstrates how **multi-agent AI systems can interact with and actively modify a structured 3D environment**.

Unlike a traditional chatbot, RoomForge allows users to collaborate with AI through a visual and interactive workspace.

The project combines autonomous agent orchestration, tool calling, structured state management, long-term memory, and interactive 3D visualization to create a practical application for interior design.
